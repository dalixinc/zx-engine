# JSSpeccy 3.2, as used by the Atlantis web page

These files are the unmodified `jsspeccy` folder of the JSSpeccy 3.2
release archive, by Matt Westcott:

- release: https://github.com/gasman/jsspeccy3/releases/tag/v3.2
  (`jsspeccy-3.2.zip`, SHA-256
  `5434b5565da96a05089491f722c8fbcd8b3b70ab0277746309d2ee1db1fdbcb9`)
- source code for exactly this version:
  https://github.com/gasman/jsspeccy3/tree/v3.2

Left out of the archive: the source map (`jsspeccy-core.wasm.map`) and
macOS `.DS_Store` files. `README.md` is the project's own.
