; wheel.txt - the Trigon wheel bomb, 12x12, drawn as a PLACEHOLDER.
;
;   #  = ink pixel       (the rim, the legs, and the T)
;   .  = transparent     (the sea shows through)
;
; There is no solid hub. The T has a one-pixel gap of water all the way
; round it, so the sea (and, where they overlap, the diver or the fish)
; shows between the mark and the rim. The bomb's own ink colour is what
; makes the T readable. That colour is chosen per bomb in wheel.asm.
;
; Edit any row. Every frame must stay 12 characters wide and 12 rows
; tall, using only those two characters. Blank lines and lines that
; start with ; are comments. Then run make (it calls tools/gfx2asm.py).
;
; A 12-pixel row does not fill a whole number of bytes. Shifted right
; by 0 to 4 it fits in 2 bytes. Shifted by 5, 6 or 7 it spills into a
; third. The converter stores each copy at its own width, and writes
; wheel_shift_bytes so the drawing code knows which.
;
; mirror off
;   The fish and the diver are mirrored to face left. This sprite is
;   not: the T has to stay a T, not a backwards one. Only the legs
;   change from frame to frame.
;
; What is fixed in every frame
;   The rim, and the Trigon mark. The mark is a tiny serif capital T,
;   the same in all four frames, and it stays upright:
;       #####       top bar, five pixels including the serifs
;       # # #       the end pixels drop down one row (the serifs),
;         #         and the stem is one pixel wide
;         #
;        ###        a small foot, three pixels wide
;   On this grid the bar is columns 3-7 of row 4, the dropped serifs
;   are row 5 columns 3 and 7, the stem is column 5 of rows 5-7, and
;   the foot is row 8 columns 4-6. Columns and rows count from 0 at
;   the top left. Row 3, row 9, and the pixels either side of the bar
;   and the foot are water, so the mark never touches the rim.
;
; What rotates
;   The legs around the rim, 90 degrees counter-clockwise each frame.
;   That is the way a wheel turns when it rolls to the left. Four
;   frames, not eight: the diagonal positions would be another copy
;   of the whole sprite, and four is enough to read the spin. One
;   leg is a wide block (the tread). The other three are short. A
;   symmetric plus-sign would look the same after a quarter turn.
;
; Frame 0  wide leg up
; Frame 1  wide leg to the left
; Frame 2  wide leg down
; Frame 3  wide leg to the right
;
